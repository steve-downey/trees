
#+TITLE: Foldable Applicative Traversable

* Ranges vs ZipList

** Ranges (nondeterminism)
- Cartesian product

** ZipList (data parallel)
- position-wise

#+begin_src cpp
auto r = smd::invoke_with<smd::zip_list_map<int>>(f, xs);
#+end_src

* Tree Applicatives

** Default (Monad-derived)
#+begin_src cpp
auto r = smd::invoke<FixTree<int>>(f, x);
#+end_src

- substitution / grafting
- expands structure

** ZipTree (explicit)
#+begin_src cpp
auto r = smd::invoke_with<smd::zip_tree_map<int>>(f, x);
#+end_src

- position-wise
- data parallel

* Key Point

- same type
- multiple lawful Applicatives
- semantics must be explicit

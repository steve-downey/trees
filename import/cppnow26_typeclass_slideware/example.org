** Not a virtual interface

** The core idea
A typeclass object is a named record of operations, found by variable-template lookup, optionally supplied explicitly or as an NTTP.

* The concept_map machinery
** What problem this solves
- Need generic algorithm names across unrelated types
- Need open extension
- Need optimizer-visible code
- Need alternate instances for testing and experiments

** How dispatch works
- Implicit lookup via variable template
- Explicit map parameter
- NTTP map parameter

** Three APIs side by side
- Raw tree API
  - ~push_left~, ~view_left~, ~concat~, ~measure~
- ranges-style API
  - iteration, views, algorithms
- typeclass API
  - ~fold_map~, ~invoke~, ~traverse~

* Foldable
** Foldable as summary, not iteration syntax
- ~Foldable~ is fundamentally about summarizing a structure
- Monoidal accumulation is the semantic center
- Iteration is an operationally useful derived view

** Why not just ranges?
- ~ranges~ answers: how do I iterate this?
- ~Foldable~ answers: how do I summarize this lawfully?
- They can interoperate
- They are not the same abstraction

** The minimal Foldable interface
- Required
  - ~fold_map~
- Derived
  - ~fold_left~
  - ~fold_right~
  - ~length~
  - ~to_vector~
  - predicates

** Design choice: tree Foldable order
- Order is observable
- Pick one order
- Document it as part of the instance

* Traversable
** Traversable is where everything meets
- effectful, shape-preserving mapping
- requires Applicative
- depends on order

** Shape plus positions
- Informal model
  - shape
  - ordered positions
- Traversal preserves the shape and visits the positions in order

* Trees as motivating instances
** Why these tree families
- ~fix_tree~: simplest abstraction-first instance
- ~fringetree~: decomposition and boundary summaries
- ~fingertree~: measured operational payoff

** Domain API versus typeclass API
- Domain API keeps good tree names
  - ~push_left~, ~view_right~, ~measure~
- Typeclass API keeps generic names
  - ~fold_map~, ~invoke~, ~traverse~

** Measures and Monoid
- ~measure~ is ~fold_map~ in operational form
- This is what makes fingertrees useful
